/dev/null — это специальный файл устройства в Linux, который работает как корзина: 
- Всё, что в него отправляется, исчезает навсегда
- При чтении из него сразу возвращается EOF (пустота)

Используется для подавления вывода:
- command > /dev/null     — скрыть стандартный вывод
- command 2> /dev/null    — скрыть ошибки
- command > /dev/null 2>&1 — скрыть всё

В нашем скрипте мы используем 2> /dev/null, чтобы скрыть сообщение об ошибке
"файл не найден", которое генерирует команда test ([ -f ... ]).
