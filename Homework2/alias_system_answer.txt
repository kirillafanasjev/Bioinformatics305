Чтобы алиас работал для всех пользователей системы, нужно его добавить в глобальный файл конфигурации: /etc/bash.bashrc - bash основной файл для всех пользователей; /etc/profile — глобальный профиль для всех оболочек.

sudo nano /etc/bash.bashrc - после этого алиас будет доступен для всех пользователей системы при следующем входе.
